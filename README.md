<h1>Explicación de lo realizado</h1>

Lo que se realizo fue la integracion de un combo box endonde se puede elegir el modeo de IA que se quiere usar,
para saber que funciona el cambio del modelo y no se queda solo elegido entramos a devtools en la seccion network,
entramos al modulo Fetch/XHR y hacemos una pregunta selecionando cualquier modelo de nuestro interes e inmediatamente se creara
un apartado llamado chat
